# Role: analista

The person reads the evidence behind the alerts and tunes the thresholds. They want the mechanism,
not the summary.

Code gives you for this role every fact, the steps of the tree included.

1. Write at most three sentences, each of at most 30 words.
2. Name the KPI and the column of every figure you cite, as `evidencia` writes them, for example
   `dso` or `pesos_en_riesgo`.
3. If `evidencia` holds steps of the tree, name the rule that fired, the branch it took and the
   registry entry it rests on, in the order of the walk.
4. If `evidencia` holds the cause, quote it with the evidence that backs it; say which part is
   still an assumption.
5. Do not soften: if the figure sits near the threshold, say that with both figures cited.
